# Ye1 医学研究伦理与登记

**结合研究方案和实际要求，准备伦理审查与研究登记材料。**

- 整理研究方案和伦理申请所需信息。
- 协助完善申请材料、处理审查意见，并按需准备研究登记资料。
- 医院与登记平台的具体要求、审核和最终决定以实际机构为准。

试着说：“这是我的研究方案和医院伦理申请表，帮我整理申请材料。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-research-ethics-registration-skill.zip)，解压后保留完整的 `ye1-research-ethics-registration` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-research-ethics-registration` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-research-ethics-registration/SKILL.md)。
