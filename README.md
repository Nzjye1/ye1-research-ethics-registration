# Ye1 医学研究伦理与登记

**结合研究方案和医院要求，协助准备伦理审查与研究登记材料。**

面向支持 Skill 指引的各类 AI Agent，用自然语言交办任务。

## 能做什么

- 结合医院要求、研究方案和已有资料，梳理伦理审查所需材料。
- 按医院模板准备申请表、研究方案相关内容、知情同意及其他适用文件。
- 检查研究方案、申请表和登记信息之间的一致性，提出可落实的完善建议。
- 整理伦理审查意见，修改相关材料并准备逐条回复。
- 按研究类型和平台要求预整理研究登记或备案资料。
- 衔接已形成的临床研究方案、收数方案和空白 CRF，继续准备送审材料。

## 安装到你的 Agent

将下面这段话发给你的 Agent：

> 请从 https://github.com/Nzjye1/ye1-research-ethics-registration 获取 Ye1 医学研究伦理与登记。读取 `skills/ye1-research-ethics-registration/SKILL.md`，按照当前 Agent 支持的方式安装完整 Skill 文件夹并检查所需工具，然后告诉我如何开始使用。

也可以下载 [通用 Skill 包](downloads/ye1-research-ethics-registration-skill.zip)，解压后将完整文件夹导入或放入所用 Agent 的技能目录；WorkBuddy 用户可使用 [WorkBuddy 导入包](downloads/ye1-research-ethics-registration-workbuddy.zip)。

根据任务使用当前 Agent 可用的检索、文件和文档工具。

## 开始使用

你可以从当前最需要的环节开始，把下面适合你的一段话发给 Agent。

### 1. 从研究方案开始

> 我有一份临床研究方案，准备申请本院伦理，请帮我查找医院的申请要求和表格，整理需要准备的材料。

### 2. 按医院表格准备申请

> 请根据这份研究方案和本院伦理申请表，填写已有信息，准备申请材料，并集中列出需要我确认的内容。

### 3. 完善知情同意和数据保护

> 请结合这项研究和医院要求，准备知情同意材料或相关申请说明，并整理数据保护和研究风险的处理安排。

### 4. 检查送审材料

> 我已经准备了方案、申请表和知情同意书，请检查内容是否一致，找出影响送审的问题，并提出具体修改建议。

### 5. 回复伦理审查意见

> 这是伦理委员会给出的意见，请逐条整理解决办法，修改相关材料，并准备一份对应回复，标明修改位置。

### 6. 整理研究登记资料

> 请根据已有研究方案和伦理材料，按指定登记平台的要求预整理题目、设计、研究对象、结局和其他需要的登记信息。

### 7. 承接已有研究方案

> 前面已经形成了研究方案和收数表，请直接使用这些资料，继续准备本院伦理申请和相关登记材料。
