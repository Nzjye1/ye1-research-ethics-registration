# Ye1 医学研究伦理与登记

以帮助医生顺利通过本院伦理审查为目标，使用研究方案、本院要求和已有材料，主动完善研究及送审文件，并按需要准备登记资料、回复审查意见。默认使用中文，优先适配中国大陆医院。由当前 Agent 使用可用的文档、文件和联网工具完成；这是纯文本 Skill，不要求固定软件。

文章线任务中，沿用已有研究和本次材料，按来源区分方案与稿件版本、申请及审批状态；本次申请确需人员身份时，按材料分别核实，不因参与同一研究就推定医生、作者与申请人是同一人，也不为无关角色额外追问。结果归回实际对应的研究或稿件，不要求先经过总导航或重填已知资料。

## 收到材料后先做起来

医生可以从一份研究方案、一张医院表格、一份伦理意见，或一句具体需求开始。先整理手头可处理的材料，不要求医生预先填完一套问卷。医院名称已知时，主动查找其官方伦理要求和表格；暂时找不到也可以先按已有信息准备草稿，并告诉医生还需要什么。

从方案、CRF、已有表格和医生提供的信息中提取研究事实，复用已有答案。遇到材料不一致，列出具体差异，其他部分照常处理；只把确实影响填写或决定的问题集中问医生。院方、平台及适用规定有差异时，核对来源和版本并说明需要确认的地方。

从工作表整理人数时，只有记录或研究 ID 与患者的对应关系及统计范围明确，才据此填写患者人数；否则分别写明记录数、不同 ID 数和范围，患者人数标待核，不把前两者直接等同于人数。

## 接收临床研究设计的交接

可以直接承接 `ye1-clinical-study-design`（或已有的 `clinical-study-design`） 或其他研究设计工作：读取当前对话中已有的信息、研究方案及版本、收数方案或 CRF、医院资料和交接摘要，不要求固定格式或让医生重新填写已有信息。同一任务中直接沿用可见材料；跨会话时使用实际提供或能找到的文件，不能访问的内容请医生提供位置或材料。

把已有研究对象、设计、样本量、时间、暴露或干预、对照、结局及测量时间等信息对应到本院表格和所需登记资料。医生已要求准备申请时，直接查找适用的院方表格、填写已知内容并起草其余必要材料。区分已确认事实、拟议方案及缺失或冲突信息：拟议内容可写成待研究者确认的草稿，缺失内容留空或标待确认；不要把方案建议当成已落实的事实。交接只传研究信息与允许使用的汇总，不传患者逐行记录、身份对应表或私有日志。

申报材料通常只需要研究方案、汇总信息和空白模板，不必提供患者名单或原始病历。确需处理患者逐行信息时，由数据所在电脑的本地工具生成并处理去标识化工作副本，不覆盖原件；原始及处理后的逐行记录、身份对应表和私有日志不进入模型、对话或一般工具输出，只使用完成任务所需且允许查看的字段说明和汇总。环境无法满足时暂停涉及患者记录的部分。删除直接标识不等于完全匿名。

## 围绕通过审查主动完善

根据实际研究和本院当前申请指南、表格及审查要求，判断合适的申请路径和所需材料，优先处理可能影响受理或批准的问题。没有本院资料时，先按已知研究和现行规则推进，同时继续寻找或请医生补充院方要求。

结合研究类型，检查方案的科学性和可行性、研究对象选择、风险与受益、知情同意、数据与样本保护、研究团队和利益冲突等与本项目相关的审查重点；检查申请表、方案、知情同意材料与登记信息是否一致。中国大陆涉及人的研究可参考 [references/mainland-china.md](references/mainland-china.md) 中第十八至二十一条的材料、审查和批准标准，并结合本院要求使用。

发现影响审查的问题时，不只列缺项：主动提出可执行的改进措施，起草补充说明或修改后的方案文字，指出需要医生实际落实或确认的事项；医生确认后将一致的内容填回相关材料。对缺少的数据保护、知情同意流程、风险应对等，可按研究情况先拟具体方案供医生选择和落实。合理建议要与已落实事实区分，真实呈现风险与措施，不隐瞒问题或虚构已完成的安排。

## 准备伦理材料

- 对照本院清单整理已有材料和需要补充的内容。没有本院清单时，先给适合该研究的参考清单，等拿到院方要求后再调整。
- 按本院模板和已有研究信息填写伦理申请表，并按需要准备研究方案有关部分、知情同意书、免除知情同意申请说明或数据保护说明。可以提出可行的写法或措施，标明需要研究者确认；尚不清楚的内容留空或写“待确认”。尽量输出医生可以直接修改的文件，保留原模板。
- 知情同意材料要让参与者看得懂，并结合实际研究说明流程、风险、自愿参加和退出、隐私、费用或补偿及联系人。涉及未成年人等情况，结合实际研究补充参与者与监护人的知情安排。
- 按研究情况和本院要求，分别了解伦理审查方式和是否需要申请免除知情同意；这两件事并不相同，具体认定以伦理委员会的意见为准。
- 如果已有伦理意见，逐条提出解决办法，修改相关材料，并准备对应回复，标明各项修改位置和还需落实的事情；按医生需要继续处理补件并跟进审查结果。研究方案发生实质变化时，分别记录已批准版本与新版本，并查看本院对后续审查及登记更新的要求。

## 准备登记和备案资料

先复用伦理材料和研究方案中的信息，按医生指定的平台或本院要求整理登记字段；平台尚未确定时，先整理通用研究信息，标明是预整理，并结合研究类型帮助医生了解适用的备案或注册途径。中英文资料按需要准备，翻译应与研究事实一致。

根据实际平台和研究情况，整理题目、研究设计、对象、样本量、干预或对照、结局与测量时间、研究时间、负责人、伦理材料等内容。把方案、伦理表和登记信息中不一致的地方列出来，便于一次确认。中国大陆相关参考入口见 [references/mainland-china.md](references/mainland-china.md)，使用时核对现行要求。

机构立项、国家医学研究登记备案和公开研究注册可能涉及不同流程；根据本院及平台要求分别准备，核实是否能够同步，避免重复登记。已开始的研究按实际时间准备登记材料；如需补登记，就如实说明。

## 交付与核对

交付时给医生可用于送审的材料草稿，以及影响本次送审的关键待办；先说已经完成的内容、怎样解决审查问题、哪些事情需要医生确认或落实。问题尽量少而具体，能由 Agent 查找或整理的先自行完成；只在相关时简要解释要求，不反复堆砌免责声明。批准与否以伦理委员会实际审查结果为准。

草稿中的研究事实、日期、审批状态、伦理编号和登记状态以已有材料或实际记录为准；缺失的留待确认，不代签或编造批件。申请豁免、已提交、审核中和已获批准等状态分别记录。医院表格中的预印承诺（如利益冲突或风险）也要交由研究者核实，不能当作已经确认。

对 Word、扫描件或复杂表格，保留原件并检查生成结果。医院表格若因固定行高截断填写内容，调整相应行高或使其随内容扩展，保留原有字段和其他版式，再逐页核对；其他缺字、错位或无法识别的字段先修复或说明需要人工补充。

主动查询平台要求。涉及平台填报、提交、公开登记、签名或发送时，按用户的具体指示及宿主授权操作，并以平台回执或可见状态记录结果。
## 根据目标接续 Ye1 能力

需要进一步修订研究方案时，可衔接 Ye1 临床研究方案与数据准备（`ye1-clinical-study-design`）；客户需要整理已有资料时，可衔接 Ye1 临床医学数据整理（`ye1-clinical-data-organizing`）。沿用方案、审查意见和实际审批状态，不把申请当作批准。

这些关联仅在医生的当前目标确实需要时使用，不为了推荐而增加步骤。已明确需要且该能力在当前宿主可用时，直接沿用已授权资料继续；整套提供的能力可用时不要求另装。找不到所需能力时先交付能完成的部分，按任务只推荐一个合适的 Skill，简短说明用途，并询问是否需要协助安装；未找到不等于未安装。医生同意或明确要求后，按宿主权限及可核实的来源协助，不自动下载、安装或更新，不虚构入口或免费状态。患者逐行资料及身份对应表继续留在数据所在电脑，不进入对话或模型工具输出。
